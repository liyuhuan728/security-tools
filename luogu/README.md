## 文件怎么命名

**`题号-题名.cpp`**，例如：

```
P1001-A+B Problem.cpp
P1047-校门外的树.cpp
```

题号从洛谷题目页复制，这样文件夹按题号排序，一眼能看出进度。

---

## 每份代码里建议留三行注释

```cpp
// 题目: P1001 A+B Problem
// 思路: 直接读入两个整数相加输出
// 卡住的地方: 无 / 或者写"一开始没处理负数"
```

第三行最重要。三个月后你回看，知道当时卡在哪，比知道答案有用。

## 提交流程

1. 把写好的 `.cpp` 存进这个 `luogu` 文件夹
2. 双击仓库根目录的 **`push.bat`**
3. 输入一句话说明（比如 `add P1001 P1002`），回车
4. 完事，代码已经在 GitHub 上了

> 说明写英文或拼音最稳，中文在某些终端里可能乱码。

---

## 多久传一次（不用每题一传）

**push.bat 会把 luogu 文件夹里所有新文件一次性全传上去**，所以攒几题一起传完全没问题。

| 节奏 | 说明 |
|---|---|
| **每天一次**（推荐） | 睡前双击一次，把当天写的题全传掉。最省事，也不容易忘 |
| 一周 2-3 次 | 也行，只要别断太久 |
| 一个月一次 | 不行。提交时间线会看起来像"突击做的" |

**底线：至少一周一次。** 面试官看的是提交时间线——"这人 9 月开始，一直有更新"比"这人一次传了 30 题"有说服力。

说明那句话可以写多个题号，一次传完当天的：

```
add B2003 B2005 P1001
```

> 传上去之后本地文件不会消失，代码一直在你电脑里。
