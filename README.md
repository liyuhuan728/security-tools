## 01. port_scanner.py —— 多线程 TCP 端口扫描器

**它回答的问题**：一台主机对外开了哪些门？

### 怎么跑

```bash
# 扫本机 1-1024 端口（第一次就跑这个）
python port_scanner.py 127.0.0.1 -p 1-1024

# 扫指定端口
python port_scanner.py 127.0.0.1 -p 80,443,3306,8080

# 扫另一台局域网设备（必须是你自己授权的设备）
python port_scanner.py 192.168.1.100 -p 1-5000 -t 200

# 网络慢 / 目标远，把超时调大
python port_scanner.py example.com -p 1-1000 --timeout 2
```

### 参数说明

| 参数 | 默认 | 作用 |
|---|---|---|
| `host` | `127.0.0.1` | 目标主机，IP 或域名 |
| `-p / --ports` | `1-1024` | 端口范围，支持 `1-1024` 或 `80,443` |
| `-t / --threads` | `100` | 并发线程数。**别调太大**，容易把对方当攻击 |
| `--timeout` | `0.5` | 单端口超时秒数，网络差调 1~2 |

### 实测结果（2026-09-28，本机）

```
80    HTTP 网页
135   Windows RPC
443   HTTPS 加密网页
445   Windows 文件共享
耗时 2.78 秒 / 500 个端口 / 60 线程
```

### 我在这份代码里学到的

- `socket` 是网络编程的地基，`connect()` 成功 = TCP 三次握手完成
- 为什么必须多线程：串行扫 1024 个端口要几分钟，并发后 3 秒
- 网络编程里"连不上"是**正常结果**，不是 bug，所以要用 `try/except` 兜住
- `settimeout()` 是扫描器的命门：不设超时，一个不响应的端口就能卡死整轮

### 下一步可以加什么（练手升级路线）

1. **Banner 抓取**：连上之后 `recv()` 收一段欢迎信息，能看出服务版本（比如 `SSH-2.0-OpenSSH_8.9`）
2. **UDP 扫描**：UDP 不握手，判断逻辑完全不同（ICMP 不可达 = 关闭）
3. **结果导出**：把扫描结果存成 JSON/CSV，做成报告
4. **服务指纹**：根据 banner 猜具体软件版本——这就是 nmap 干的事

> 做到第 4 步，你就基本复刻了一个迷你 nmap。

## ⚠️ 法律与道德底线

**只扫你自己拥有的设备，或拿到明确书面授权的测试目标。**

未经授权扫描他人主机，在国内可能触犯《网络安全法》与《刑法》第 285 条（非法侵入计算机信息系统罪）。
这门专业教你守住系统，不是教你破别人的门——**这条线从第一行代码就要立住，而且它会是你简历上真正的加分项：面试官看得出来一个人有没有职业底线。**
